WebAssembly bridge and CLI commands

  • crates/verdant-wasm compiles verdant-core to WebAssembly for OffscreenCanvas workers, 16x16 tile rendering, AudioWorklet synthesis, and #vdnt= URLs.
  • cargo run -p verdant-cli -- pack-scene <out.glb> packs a validated .glb, .vdnt world snapshot, and .uorc stream.
  • cargo run -p verdant-cli -- verify-uorc <file.uorc> verifies UORC-SHA256-CHAIN-v1 multi-LOD archives.
  • cargo run -p verdant-cli -- validate-glb <file.glb> and validate-wgsl <file.wgsl> run Khronos and W3C validators.
  • cargo run -p verdant-cli -- benchmark profiles 120 headless simulation frames against the 60fps budget.
