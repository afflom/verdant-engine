CLI subcommands in crates/verdant-cli

  • verdant import-glb <file.glb> imports nodes, meshes, skeletons, keyframe clips, and PBR materials.
  • verdant transcode-glb <in.glb> <out.uorc> [seed] transcodes an authored GLB into a portable four-LOD UORC stream.
  • verdant pack-portable-uorc <out.uorc> [seed] and verify-portable-uorc <file.uorc> pack and verify stateless Wasm streams.
  • verdant pack-scene <out.glb>, validate-glb, validate-wgsl, snapshot-verify, and benchmark validate assets in CI.
