Verdant Engine is a universal 3D game and interface engine written in Rust and WebAssembly.

Every pass runs on scene worlds, bounding volume hierarchies, XPBD physics, WGSL shaders, glTF 2.0, and UORC streaming.

It also verifies 2D and 3D UI compliance, local SLM commands, and Stitch peer shards.

Words on this page 5
scene world
The entity-component-system container in verdant-core that stores entities, parent-child transforms, meshes, and PBR materials.
bounding volume hierarchy
A tree of 3D bounding boxes partitioned by surface area so raycasts, diegetic UI picks, and camera frustum checks skip distant geometry.
WGSL
The W3C portable shading language whose modules are parsed and type-checked in Verdant Engine by naga.
glTF
The Khronos Group 3D scene transmission standard. GLB is its single-file binary container.
UORC
Universal Object Reference Compression: progressive SHA-256 chain-verified multi-frame compression streaming 3D scenes up to lossless resolution.
