Build your first 3D world

Create a Rust 3D scene, step rigid-body physics, and export a binary asset.

Kai Game developer

“Walk me from an empty Cargo crate to a running 3D scene.”

A tutorial: follow the steps in order. Each step builds on the one before it.

Run the starter template

The repository ships a playable project in templates/browser-3d-starter so you can run a 3D game world right away.

cargo run --manifest-path templates/browser-3d-starter/Cargo.toml

That command builds verdant-core, validates all four built-in WGSL shaders, steps GJK beacon triggers and NavMesh steering, and writes custom-starter-world.glb.

Spawn terrain and child beacons

Open templates/browser-3d-starter/src/main.rs to inspect how a scene world organizes 3D objects.

You spawn a root terrain patch first, attach three fluted columns and skinned beacons as children, and build the bounding volume hierarchy.

let mut scene = SceneWorld::new();
let ground_id = scene.spawn("StarterTerrain", EntityRole::TerrainPatch, None, Transform::default(), bounds, (1.0, "Terrain"));
let beacon_id = scene.spawn("NorthBeacon", EntityRole::StaticArchitecture, Some(col_id), Transform::from_xyz(0.0, 4.6, 0.0), beacon_bounds, (1.0, "Beacon"));
let bvh = scene.build_bvh();

Capture a world snapshot and UORC stream

Before exporting the scene, encode a world snapshot and a multi-LOD UORC stream with SHA-256 verification.

let snap_bytes = WorldSnapshot::encode(&lod_scene)?;
let restored = WorldSnapshot::decode(&snap_bytes)?;
let uorc_bytes = pack_progressive_uorc_stream(7)?;

Play the starter arena in the browser

Serve templates/browser-3d-starter over HTTP and open index.html to pilot the Kinetic Probe with WASD keys and activate all three beacons.

Words on this page 6
scene world
The entity-component-system container in verdant-core that stores entities, parent-child transforms, meshes, and PBR materials.
bounding volume hierarchy
A tree of 3D bounding boxes partitioned by surface area so raycasts and camera frustum checks skip distant geometry.
WGSL
The W3C portable shading language whose modules are parsed and type-checked in Verdant Engine by naga.
glTF
The Khronos Group 3D scene transmission standard. GLB is its single-file binary container.
UORC
Universal Object Reference Compression: progressive SHA-256 chain-verified multi-frame compression streaming 3D scenes up to lossless resolution.
world snapshot
A deterministic binary save of tick count, streaming LOD rank, and entity transforms protected by a 32-byte SHA-256 digest.
